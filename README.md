# Dota 1x6 Analytics

Unofficial Windows desktop application for Dota 1x6 match analytics.

## Features

- Match and opponent statistics
- Hero and legendary talent analytics
- Match history and KDA
- Local history cache
- System tray and automatic update checks

Download the application from GitHub Releases.
